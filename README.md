# 🚀 WD Week 3 – JavaScript Fundamentals (Part 1)

## 📌 About the Project
This project is part of my Week 3 Web Development Internship assignment. It focuses on learning JavaScript fundamentals and building a strong foundation in programming logic.

## 🎯 Topics Covered
- JavaScript Syntax and `console.log()`
- Variables: `let` and `const`
- Data Types: String, Number, Boolean, `undefined`, and `null`
- Checking Data Types using `typeof`
- Arithmetic, Assignment, Comparison, and Logical Operators
- Increment and Decrement Operators
- Conditional Statements: `if`, `if...else`, `else if`, and Nested `if`
- Loops: `for`, `while`, and `do...while`
- Five JavaScript Practice Programs

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ▶️ How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Open Developer Tools → Console to view the JavaScript output.
4. Review each JavaScript file to understand the examples.
